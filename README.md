# LTD Grove Street

Homepage premium pour une épicerie de roleplay **GTA FiveM** — *LTD Grove Street*.
Style street-editorial, ambiance cinématographique sombre, néons violet/magenta et touches chrome.

> **« La rue. Le prestige. »**

## ✦ Aperçu

Page d'accueil statique (HTML + CSS, sans dépendances) :

- **Hero** plein écran — devanture de magasin in-game, tagline forte et CTA *« Découvrir la boutique »* avec halo magenta.
- **Produits** — 3 pièces signatures (boisson, snack premium, kit de survie) en cartes éditoriales, prix et survol bordure violette.
- **À propos** — récit d'ambiance avec divider chrome et accent violet à gauche.
- **Footer** — localisation (Grove Street, Los Santos), horaires 24/7 et liens Discord / contact.

## ✦ Lancer en local

Aucune build nécessaire — ouvrir le fichier directement :

```bash
# macOS / Linux
open index.html        # ou : python3 -m http.server 8000
```

```
index.html    # structure de la page
styles.css    # thème, grille & animations
```
